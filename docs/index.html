Questions

Asked by every teacher first

Do students need internet?

No. ClassCast runs on a hotspot made by the teacher's phone or the school's local network. Nothing goes to the cloud, so a dead data plan or a no-signal classroom changes nothing.

Which devices does it run on?

Android 12 and newer for phones, and Windows 10/11 (64-bit) for the teacher's laptop. Students install the Android app; the laptop build is meant for presenting.

Is it free? Do I need an account?

Free, and there is nothing to sign up for. No email, no password, no license key — students type a name and they are in.

Can students flip ahead on their own?

Only if you allow it — and one tap of “take control” pulls every screen back to your page. For a video, pause or freeze stops the whole room on the same second.
