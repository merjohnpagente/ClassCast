FAQ

Before you download.

Short answers to the things teachers ask first. Everything here is already in the app, not planned.

Ask on GitHub
Do the students need internet?

No. ClassCast runs on the hotspot made by the teacher's phone, or on the school's local network. Nothing goes to a server, so a dead data plan changes nothing.

Which devices run it?

Students install the Android app on Android 12 or newer. The teacher's laptop runs the Windows build on Windows 10/11 (64-bit). The iOS build is unsigned and is signed on a Mac — see the note below.

Is it really free, with no account?

Free, and there is nothing to sign up for. No e-mail, no password, no licence key.

Can a student flip ahead on their own?

Only if you allow it. One tap of "take control" pulls every screen back to your page, and freezing a video stops the room on the same frame.
