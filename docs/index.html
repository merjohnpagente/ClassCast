What the app does

Everything below ships in the build you download. Nothing here is a roadmap.

One page, every screen

Turn a page, switch to scrolling, zoom into a diagram. Every student's phone moves with you.

The phone is the server

A hotspot or the school's own network is all it needs. No cloud account, no uploads.

Video on one clock

Pause, seek or freeze the room and thirty phones stay on the same second.

The real file, not a picture

PDF, PowerPoint, Word, Excel, images and video, rendered in the app with page counts the class can sync on.

One scan and they're in

The code carries every address the phone answers on. Students type a name — no email, no password.

Dark mode included

A night palette that follows the phone, as calm at 8pm as it is at 8am.

One phone leads. The rest follow.

The teacher's screen is the only one that leads. Pages, scrolls, zooms, pauses and freezes travel out from it to every phone in the room — no internet carrying any of it.

Before you download

Do the students need internet?

No. ClassCast runs on the hotspot made by the teacher's phone, or on the school's local network. Nothing goes to a server, so a dead data plan changes nothing.

Which devices run it?

Students install the Android app on Android 12 or newer. The teacher's laptop runs the Windows build on Windows 10/11 (64-bit). The iOS build is unsigned and is signed on a Mac — see the note below.

Is it really free, with no account?

Free, and there is nothing to sign up for. No e-mail, no password, no licence key.

Can a student flip ahead on their own?

Only if you allow it. One tap of "take control" pulls every screen back to your page, and freezing a video stops the room on the same frame.
